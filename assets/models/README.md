# Models

`fantasy_cottage_v2.glb` is generated by `blender/sync-custom-world.ps1`. The builder is its editable source. V1, if present, is a separate file and is never overwritten by the default build.

The root Three.js prototype can prepare instances without changing existing procedural buildings:

```js
import { GLTFLoader } from 'https://esm.sh/three@0.181.0/examples/jsm/loaders/GLTFLoader.js';
import { createGlbLibrary, fantasyCottageV2Url } from './assets/glb-loader.js';

const models = createGlbLibrary(new GLTFLoader());
try {
  const cottage = await models.instantiate(fantasyCottageV2Url);
  scene.add(cottage);
} catch (error) {
  console.error('Could not load cottage; keep the existing procedural building', error);
}
```

Serve the repository over HTTP; browser module and GLB loading may fail via `file://`. Instances share geometry and materials; do not dispose or mutate them per instance. The model has many individual meshes, so profile draw calls before adding many copies. This loader is prepared for integration, but does not replace any existing scene buildings automatically.
